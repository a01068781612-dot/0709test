# 2단계 · 강의 영상에서 자막과 차트 프레임 뽑기

`scripts/lecture_extract.py` 하나로 두 가지를 만든다.

| 산출물 | 위치 | 내용 |
|---|---|---|
| 자막 | `output/자막/<영상>.srt`, `<영상>.txt` | 한국어 STT(whisper). srt 는 타임스탬프 포함, txt 는 `[00:14:32] 문장` 형태 |
| 프레임 | `output/프레임/<영상>/0014m32s.jpg` | 장면이 바뀐 순간의 화면. 파일명이 분·초, 가로 1280px |
| 요약 | `output/요약.md` | 영상별 길이 · 자막 구간 수 · 프레임 감지→저장 장수 |

## 1. 준비

```bash
python scripts/lecture_extract.py check
```

없는 것이 있으면 아래 명령을 알려준다.

- **ffmpeg** — Windows `winget install Gyan.FFmpeg` · macOS `brew install ffmpeg` · Ubuntu `sudo apt install ffmpeg`.
  설치가 번거로우면 `pip install imageio-ffmpeg` 만 해도 스크립트가 그 안의 ffmpeg 를 찾아 쓴다.
- **faster-whisper** — `pip install faster-whisper`. NVIDIA GPU 가 있으면 `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12` 추가.
  (`pip install openai-whisper` 도 지원. 둘 다 있으면 faster-whisper 를 먼저 쓴다.)
- whisper 모델은 첫 실행 때 자동으로 내려받는다. medium 은 약 1.5GB, 인터넷이 필요하다.

## 2. 실행 순서

```bash
# 영상 목록과 길이
python scripts/lecture_extract.py list

# 첫 번째 영상의 앞 5분만 시험 (산출물 이름에 _앞5분 이 붙는다)
python scripts/lecture_extract.py run --test

# 결과가 괜찮으면 전체
python scripts/lecture_extract.py run
```

폴더를 생략하면 `~/OneDrive/바탕 화면/네이버카페영상` → `~/Desktop/네이버카페영상` 순으로 찾는다. 하위 폴더(`1,2강/` 등) 안의 영상도 모두 찾는다.
다른 위치면 첫 인자로 적는다: `python scripts/lecture_extract.py list "D:\강의\네이버카페영상"`.

## 3. 자주 쓰는 옵션

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--model` | `medium` | `small` 은 3~4배 빠르지만 한국어 정확도가 떨어진다. GPU 가 있으면 `large-v3` 권장 |
| `--select 1,3` | 전체 | `list` 번호나 파일명 일부로 일부 영상만 |
| `--scene-threshold` | `0.3` | 낮출수록 프레임을 많이 뽑는다. 화면 녹화 강의는 0.1 정도가 맞다 |
| `--interval 30` | `0` | 장면 전환과 별도로 30초마다 한 장씩 더 뽑는다. 차트가 서서히 바뀌는 강의용. `--dedup always` 와 같이 쓰면 안 바뀐 구간은 지워진다 |
| `--max-frames` | `300` | 한 영상에서 이 장수를 넘으면 중복 프레임 제거 |
| `--dedup always\|never` | `auto` | 중복 제거를 항상/절대 하지 않음 |
| `--dedup-distance` | `10` | 중복으로 볼 해시 거리(256비트 중). 키우면 더 많이 지운다 |
| `--skip-stt`, `--skip-frames` | | 한쪽만 다시 돌릴 때 |
| `--keep-work` | | 추출한 wav 등 중간 파일을 `output/_work/` 에 남김 |
| `--force` | | 이미 srt 와 프레임 폴더가 있는 영상도 다시 처리. 기본은 건너뛰므로 중간에 끊겨도 같은 명령으로 이어서 돌리면 된다 |

## 4. 동작 방식 (짧게)

- **자막** — ffmpeg 로 16kHz 모노 wav 를 뽑고, whisper 에 `language=ko`, VAD 필터, 주식 용어 힌트(`--prompt`)를 주고 돌린다.
- **프레임** — ffmpeg 의 `select=gt(scene,임계값)` 으로 화면이 크게 바뀐 프레임만 한 번의 디코딩으로 뽑는다.
  같은 프레임의 17×16 흑백 축소본으로 dHash 를 만들어 두었다가, 장수가 `--max-frames` 를 넘으면
  앞서 저장한 프레임과 해시 거리가 `--dedup-distance` 이하인 것을 지운다. 지운 목록은 `_중복제거.txt` 에 남긴다.
- 같은 초에 두 장이 잡히면 `0014m32s_2.jpg` 처럼 번호가 붙는다.

## 5. 속도 감

CPU(int8) 기준 medium 모델은 영상 길이의 1~2배가 걸린다(1시간 강의 ≈ 1~2시간). GPU 가 있으면 몇 분이면 끝난다.
프레임 추출은 1080p 기준 영상 길이의 약 1/10.

## 6. [4] 결합 — 강의 노트 만들기 (`scripts/lecture_notes.py`)

```bash
pip install fpdf2
python scripts/lecture_notes.py            # output/자막 + output/프레임 → output/노트
```

영상마다 `output/노트/<영상>.md` 와 `<영상>.pdf` 를 만든다. 문단 앞에 `[시:분:초]` 가 붙고, 그 시각의 차트 프레임이 문단 사이에 들어간다.
PDF 는 맑은 고딕(Windows) 또는 나눔고딕(Linux, `apt install fonts-nanum`)을 찾아 쓴다. 다른 폰트는 `--font 경로`.
이미 만든 노트는 건너뛰므로(`--force` 로 다시) 추출이 끝난 뒤 언제든 다시 돌려도 된다.
`_앞5분` 테스트 산출물은 무시한다. `output/노트/색인.md` 에 전체 목록이 생긴다.

추출이 끝나길 기다렸다가 자동으로 이어 붙이려면 두 번째 터미널에서:

```powershell
Wait-Process -Name python -ErrorAction SilentlyContinue; python lecture_notes.py
```
