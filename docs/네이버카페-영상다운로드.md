# 네이버 카페 영상 일괄 다운로드

카페 게시글에 붙은 영상을 **원본 화질로 한 번에** 받는다. 화면 녹화가 아니라
네이버가 내려주는 원본 파일을 직접 받으므로, 15분짜리 영상을 15분 동안
기다릴 필요가 없다.

## 왜 로컬에서 실행해야 하나

클라우드 세션은 naver.com 이 네트워크 정책으로 차단되어 있고, 브라우저의
네이버 로그인도 공유되지 않는다. 따라서 이 도구는 **본인 PC에서 실행되는
세션**에서만 동작한다.

세션이 로컬인지 확인하려면 작업 폴더를 보면 된다.

| 작업 폴더 | 판정 |
|---|---|
| `C:\Users\...` | 로컬 — 사용 가능 |
| `/home/user/...` | 클라우드 — 사용 불가 |

## 최초 1회 준비

```bash
pip install playwright requests
playwright install chromium        # 빠뜨리면 브라우저 실행에 실패한다
python scripts/naver_cafe_dl.py login
```

`login` 을 실행하면 브라우저가 뜬다. 네이버에 로그인한 뒤 터미널로 돌아와
Enter 를 누르면 세션이 저장되고, 이후로는 다시 로그인할 필요가 없다.

세션 파일은 **저장소 바깥**에 보관된다. 쿠키가 커밋되는 사고를 막기 위해서다.

- Windows: `%LOCALAPPDATA%\naver_cafe_dl\state.json`
- macOS / Linux: `~/.config/naver_cafe_dl/state.json`

## 사용

글 번호만 주면 된다.

```bash
python scripts/naver_cafe_dl.py grab 869 --list   # 먼저 감지 결과만 확인
python scripts/naver_cafe_dl.py grab 869          # 실제 다운로드
```

`downloads/` 에 게시글 캡션을 그대로 딴 이름으로 저장된다.

```
downloads/01_입문 6,7강 (3).mp4
downloads/02_입문 6,7강 (4).mp4
```

중간에 끊겨도 다시 실행하면 이미 받은 파일은 건너뛴다.

### 옵션

| 옵션 | 설명 |
|---|---|
| `--list` | 받지 않고 감지된 목록만 출력 |
| `--out DIR` | 저장 폴더 지정 (기본 `downloads`) |
| `--cafe ID` | 다른 카페 (기본 `31568077`) |
| `--debug` | 진단 정보를 `_debug/` 에 기록 |

## 동작 방식

1. 저장된 로그인 세션으로 게시글을 연다
2. 끝까지 스크롤해 지연 로딩되는 영상까지 불러온다
3. 본문의 영상 블록에서 `vid` / `inkey` 를 추출한다
4. 네이버 재생 API 로 원본 주소를 받아 **최고 화질**을 고른다
5. 내려받는다 (MP4 직접 다운로드, HLS 인 경우 ffmpeg 사용)

## 문제가 생기면

`영상 블록 0개` 가 나오면 `_debug/modules.json` 이 생성된다. 이 파일에는
게시글 본문이 아니라 영상 블록의 구조만 들어 있어, 파서를 고칠 때 필요한
정보가 여기에 다 있다.

## 주의

받은 영상은 개인 소장용이다. 재배포하지 않는다.
